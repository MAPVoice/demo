# Audio samples

현재 WAV 파일은 웹 페이지의 audio player가 정상적으로 표시되는지 확인하기 위한 무음 placeholder입니다.

실제 공개 시 다음 중 하나로 교체하십시오.

1. 기존 파일명과 동일하게 실제 WAV 파일을 덮어쓰기
2. 새 파일명을 사용하고 `assets/js/demo-data.js`의 경로 수정

권장 사항:

- WAV 또는 MP3
- 브라우저 호환성을 고려하면 PCM WAV 또는 일반 MP3 사용
- 음량 정규화 기준 통일
- 모델 간 동일한 target text와 동일한 prompt 사용
- 비공개 데이터, 동의받지 않은 화자 음성, 개인정보 포함 여부 확인
